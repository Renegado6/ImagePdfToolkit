## 🎯 How to Use

### Adding a Watermark
1. Open ImagePdfToolkit
2. Select the **"Add Watermark"** option from the main menu
3. Click the **"Add Images"** button to select one or more images
4. Type your watermark text in the provided field
5. Customize font, size, color, and position using the controls
6. Preview your watermark to ensure it looks perfect
7. Click **"Process"** to apply the watermark to all selected images
8. Choose your output folder and preferred image format
9. Click **"Save"** and your watermarked images are ready

### Converting Images to PDF
1. Launch the application and choose **"Images to PDF"**
2. Click **"Add Images"** to select your image files
3. Drag and drop to arrange image order if needed
4. Adjust page size, orientation, and margins as desired
5. Click **"Create PDF"** 
6. Select a destination and enter your file name
7. Click **"Save"** to generate your PDF document

### Converting PDF to Images
1. Open ImagePdfToolkit and choose **"PDF to Images"**
2. Click **"Select PDF"** to choose your PDF file
3. Choose the pages you want to convert (or select all)
4. Select image format (PNG or JPEG) and quality
5. Click **"Extract Images"**
6. Choose your output folder
7. The application converts each PDF page to a separate image file

## 🆘 Troubleshooting Tips

### Application Won't Start
- Make sure you have the latest version of Windows installed
- Right-click the app and select "Run as administrator"
- Check if your antivirus is blocking the application

### Slow Processing Speed
- Close other applications to free up system resources
- Process images in smaller batches for better performance
- Reduce image resolution for faster file processing

### Watermark Not Appearing
- Ensure you enter text in the watermark field
- Check that the font size isn't set to zero
- Verify your output folder has write permissions
